# 视觉与交互

使用 Operate 模式。浅灰白工具区域、深石墨画布、松绿色主动作；图像本身是视觉中心。
左侧可搜索图片目录，中间真实图像与矢量标注，右侧提示及参数，底部任务和检测结果。
首屏直接呈现工作台，无介绍页。固定参考图是核心交互：切换待测图片不会改变参考标注。
正文使用系统中文字体，14px；数字等宽；边框分隔，不用装饰性卡片。按钮具有文本名称与可见焦点。
窄屏上下排列，画布支持缩放；键盘撤销、切图；尊重减少动态效果设置。真实空态、任务失败和取消均可见。

图片画布优先占据窗口剩余高度，结果区紧凑显示。专注模式收起侧栏；缩放锚定鼠标，空格暂时切换为抓手，不改变当前标注工具或未完成多边形。
