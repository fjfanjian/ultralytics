开始一次 YOLOE 实验

  1. 打开本地图片目录，在左侧选择待测图片。
  2. 视觉模式：固定参考图，选类别，用框、区域点、画笔或多边形标注。双击结束多边形，Esc 取消未完成绘制。
  3. 点击“待测图片”，切换图片，再推理。参考图与标注不会跟随目标切换。
  4. 文本模式每行填写一个类别；无提示模式不需要标注，会自动切换到 -pf 权重。
  5. 批量任务可以取消，当前图片处理结束后停止；保留已完成结果。
  6. 导出 ZIP 包含原图路径索引、检测 JSON、归一化 YOLO 框标签、分割标签、结果图和可复用提示向量。

点选是圆形区域掩码，画笔是轨迹掩码，多边形是填充区域；它们通过官方底层视觉提示预测器编码，不是 SAM 的正负点分割。多个类别必须分别有示例。

这是图片推理 DEMO。训练、验证评测、视频跟踪、部署格式转换不在图片工作流中。检测与分割输出均来自真实模型，结果需人工复核。
