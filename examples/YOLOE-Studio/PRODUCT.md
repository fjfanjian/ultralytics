# YOLOE 本地实验台

<!-- impeccable:product-schema 1 -->

## Platform

web

## 用户与目标

在 Windows 上打开任意本地图片目录，尝试官方 YOLOE 的全部图片提示推理模式，保留可复核的结果。

## 范围

文本、视觉、无提示；框、区域点、手绘、多边形、跨图；检测框与实例掩码；批量、取消、提示文件与结果导出。
点和手绘通过区域掩码进入官方视觉预测器，不声称支持 SAM 正负点。图片推理工作台不替代训练、视频跟踪或部署格式工具。
